# SillyTavern Find & Replace（世界书 / 角色卡查找替换）

SillyTavern 扩展：批量查找并替换**世界书条目**和**角色卡**里的文字，直接修改存档。

> 与酒馆自带的 Regex 扩展不同：Regex 只在运行时改写提示词或 AI 回复，不会动存档；本插件修改的是世界书文件和角色卡本身。

## 功能

- 普通文本或**正则表达式**查找，正则替换支持 `$1`、`$<name>`、`$&`
- 可选区分大小写、**跳过 `{{char}}` / `{{user}}` 等宏**
- 范围：任意多个世界书 + 任意多个角色，支持按名字筛选
- 字段可选：
  - 世界书：内容、标题/备注、主关键词、次关键词
  - 角色卡：描述、性格、场景、开场白、备选开场白、对话示例、系统提示词、历史后指令、创作者备注、内嵌世界书
- **先预览再替换**：显示每处匹配的上下文和改动对比，可逐条取消勾选
- 替换前自动**下载备份 JSON**；支持**撤销上次替换**和**从备份文件恢复**
- 替换时重新读取最新数据，搜索后被别处改过的地方会自动跳过，不会覆盖

## 安装

酒馆中打开 **扩展（Extensions）→ 安装扩展（Install extension）**，填入：

```
https://github.com/usiumia1-ctrl/SillyTavern-FindReplace
```

## 使用

1. 点输入框左侧的魔杖菜单 → **查找替换**（或在扩展设置里点「打开查找替换」）。
2. 填写查找 / 替换内容，勾选要处理的世界书、角色和字段。
3. 点 **搜索**，检查预览，取消不想改的条目。
4. 点 **替换勾选项** 并确认。

## 注意

- 中文没有“整词”概念：把「小明」换成「小红」时，「小明天」也会被匹配，请在预览里检查。
- 撤销记录只保留在当前页面，刷新后请用下载的备份文件恢复。
- 已在 SillyTavern 1.14.0 和最新版上测试。
- 群聊和角色绑定的世界书不会被自动带上：绑定的世界书请在左侧世界书列表里勾选。
